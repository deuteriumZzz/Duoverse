# ADR-0005: нумерология — пифагорейская система
**Статус:** принято · 06.11.2026

- **Число пути:** сумма всех цифр даты ДДММГГГГ, сворачиваем до 1–9; мастер-числа 11, 22, 33 сохраняются (в отчёте показываем «33 → 6»).
- **Число судьбы:** сумма значений букв полного имени по пифагорейской таблице (кириллица А=1…Я=6 по кругу 1–9, латиница A=1…Z=8).
- **Личный год:** день + месяц рождения + текущий год.
- **Матрица судьбы:** точки из 22 арканов по дню, месяцу и году — формулы в `docs/methodology/numerology.md`. Это авторская адаптация (школы расходятся), помечена как символический слой.
Халдейская система не используется.
