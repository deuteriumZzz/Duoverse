# ADR-0001: стек UI-прототипа

**Статус:** принято · 05.11.2026

## Решение
- Django 5.2 + шаблоны + **htmx 2** (мини-демо, поллинг генерации) + **Alpine 3** (локальные состояния) + **Tailwind v4** (CLI через npm, токены в `@theme`).
- Графики (радар, кольца, шкалы, матрица рисков) — **собственный SVG** вместо Chart.js/ApexCharts: 6 категорий и 4 шкалы не требуют библиотеки, а анимации и печать в PDF полностью под контролем. Вернуться к библиотеке, если появятся интерактивные временные ряды.
- Анимации — CSS + IntersectionObserver + View Transitions API, без motion-библиотек; `prefers-reduced-motion` выключает всё.
- Иконки — Lucide (ISC), спрайт урезается скриптом `scripts/build_icons.py` до используемых (~18 KB вместо 550 KB).
- Арты арканов — генеративные SVG по номеру аркана: оригинальные, без вопросов авторских прав. Иллюстрированная колода — отдельное решение позже.
- Прототип без БД: состояние сценария в подписанной cookie-сессии. PostgreSQL — в Фазе 4.

## Последствия
Подключение бэкенда = новая реализация `ReportProvider` в `config/container.py`; шаблоны и views не меняются.
