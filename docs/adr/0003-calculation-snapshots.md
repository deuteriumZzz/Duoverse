# ADR-0003: снимки расчёта в JSONB, ключ — хэш входа + версия алгоритма
**Статус:** принято · 06.11.2026

Отчёт хранится как снимок `Report` (pydantic → JSON) в `jsonb`. Ключ кэша: `sha256(нормализованные входные данные) + algorithm_version`. Повторный запрос с теми же данными не пересчитывается; смена версии алгоритма даёт новый снимок, старый остаётся для истории и регрессионных тестов. Чувствительные поля (данные рождения, ответы анкет) хранятся отдельно и шифруются; в снимке — только результаты.
