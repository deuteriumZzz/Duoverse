# ADR-0002: без DRF; JSON-API — Django Ninja, когда понадобится
**Статус:** принято · 06.11.2026

Основной UI — серверные шаблоны и htmx-партиалы, публичного API нет. DRF/Ninja сейчас — лишний слой. Когда понадобится JSON-API (мобильное приложение, партнёры), берём **Django Ninja**: он работает на pydantic, а наш контракт уже на pydantic — схемы переиспользуются без сериализаторов.
