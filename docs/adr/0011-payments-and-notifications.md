# ADR-0011: оплата, уведомления и ежедневный слой пары
**Статус:** принято · 11.11.2026

## Оплата (ЮKassa)
- **Бесплатно:** Итог (тип пары, балл, точность), приглашение партнёра, вопрос дня на двоих, план привычек, первая сфера разбора целиком.
- **Полный разбор — 490 ₽ разово за пару.** Открывает все 13 сфер, четыре слоя с картами и PDF **обоим** партнёрам. Платить может любой из двоих.
- **Пара+ — 249 ₽ на 30 дней, без автосписаний.** Все пары плательщика целиком, квиз недели, история ответов на вопросы дня. Действует и для партнёра в связанной паре. Оплата раньше срока продлевает, а не сгорает.
- Платёж создаётся через REST API ЮKassa с `capture: true` и чеком по 54-ФЗ (`receipt`: почта покупателя, услуга, `payment_mode: full_payment`, НДС из `YOOKASSA_VAT_CODE`). Id покупки — ключ идемпотентности.
- **Статус всегда спрашиваем у ЮKassa** (`GET /v3/payments/{id}`) — уведомление и возврат на сайт лишь повод спросить; телу уведомления не доверяем.
- Без ключей магазина: в `DEBUG` — тестовая страница оплаты, в продакшене кнопка ведёт на «оплата скоро появится».

## Вопрос дня и квизы
- Вопрос дня считает сервер (по слабым сферам пары и дате); каждый отвечает со своего телефона, ответы шифруются. Ответ партнёра открывается только когда ответили оба.
- Квиз недели (12 квизов по 6 вопросов, по кругу): каждый отвечает про себя, результат с совпадениями — после двух ответов.

## Уведомления
- Telegram-бот: человек нажимает «Подключить Telegram», бот получает `/start <одноразовый код>` и привязывает чат. Вебхук защищён секретом в пути и заголовком `X-Telegram-Bot-Api-Secret-Token`.
- События: партнёр ответил на вопрос дня, прошёл квиз, присоединился к паре; вечером (`REMINDER_HOUR`) — напоминание тем, кто подключил Telegram и ещё не ответил.
- Без Telegram — короткое письмо (кроме вечернего напоминания: письма каждый день — это спам).
- Сайт устанавливается на экран телефона (manifest + service worker с офлайн-страницей). Web-push не делаем: Telegram в России работает надёжнее и уже покрывает уведомления.

## Последствия
- Нужны ключи магазина ЮKassa и бот в Telegram; чек требует почту — она есть у каждого аккаунта, вошедшего по почте. Вход только через Telegram без почты при оплате попросит почту.
- Почасовой планировщик (`scheduled_jobs`) чистит анонимные данные старше 7 дней и рассылает напоминания.
