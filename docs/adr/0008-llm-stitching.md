# ADR-0008: ИИ-сшивка — Claude Opus 5.5, структурированный JSON, проверка кодом
**Статус:** принято · 06.11.2026

- **Модель:** `claude-opus-5-5` (настройка `LLM_MODEL`), `effort=medium` (`LLM_EFFORT`). У Opus 5.5 мышление всегда включено, а `temperature` API отклоняет — «низкая температура» из промпта заменена фиксированными версиями модели и промпта и проверкой результата кодом.
- **Закрытый контекст:** модель получает только факты пары и блоки базы знаний с id (`facts_of`). Цифры, проценты и списки в отчёт попадают только из движка.
- **Формат:** `output_config.format` (JSON-схема): у каждого абзаца — `block_ids`.
- **Проверка (`apps/insights/domain/validator.py`):** неизвестные `block_ids`, абзацы без опоры, числа и планеты не из входа, запрещённые формулировки (вердикты, предсказания событий, диагнозы, клише). До 2 повторов с ошибками валидатора в запросе, затем фолбэк — отчёт из блоков без ИИ.
- **Отказы:** серверный фолбэк `fallbacks: "default"` (beta `server-side-fallback-2026-07-01`); итоговый `stop_reason: refusal` → фолбэк на блоки.
- **Кэш:** Django cache, ключ = хэш(фактов + версия промпта + модель), 30 дней. Системный промпт — кэшируемый префикс (`cache_control`).
- **Без ключа** (`ANTHROPIC_API_KEY` пуст) сшивка выключена — продукт работает и выглядит цельно на блоках.
- Стоимость и токены каждого вызова пишутся в лог (`stitch usage …`).
