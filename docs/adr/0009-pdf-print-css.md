# ADR-0009: PDF — печатная вёрстка браузера вместо WeasyPrint (пока)
**Статус:** принято · 06.11.2026

WeasyPrint требует системных библиотек (Pango/Cairo) в каждом окружении. Отчёт уже свёрстан как 3 страницы A4 с `@media print` и `@page`, «Сохранить PDF» использует печать браузера — результат тот же, без серверной зависимости. Если понадобится PDF на сервере (рассылка по почте, вложения), подключаем WeasyPrint к тому же шаблону `report/pdf.html` и добавляем Pango в Dockerfile.
