# ADR-0004: эфемериды — pyswisseph (встроенная модель Moshier)
**Статус:** принято с оговоркой · 06.11.2026

`pyswisseph` без файлов эфемерид использует аналитическую модель Moshier: точность планет — доли угловой секунды, для синастрии (орбы в градусах) более чем достаточно; файлы `.se1` подключаются позже без изменения кода.

**Лицензия:** Swiss Ephemeris распространяется по AGPL или коммерческой лицензии Astrodienst. Для закрытого коммерческого продукта нужна **коммерческая лицензия** — решение владельца до запуска. Альтернатива без ограничений — `skyfield` (MIT) с файлами JPL; адаптер `EphemerisProvider` позволяет заменить реализацию.
