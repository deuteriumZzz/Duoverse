# ADR-0004: эфемериды — Skyfield + NASA JPL DE421

**Статус:** принято · 12.11.2026 (заменяет решение от 06.11.2026 о pyswisseph)

**Было:** `pyswisseph` (модель Moshier). Swiss Ephemeris распространяется по AGPL или по платной лицензии Astrodienst: для закрытого платного сервиса пришлось бы либо открыть весь код, либо покупать лицензию.

**Решение:** [Skyfield](https://rhodesmill.org/skyfield/) (MIT) с эфемеридами NASA JPL DE421 (общественное достояние, 1899–2053, ~17 МБ). Без лицензионных отчислений и без обязательства открывать код.

Что считаем сами поверх Skyfield (`apps/astrology/infrastructure/ephemeris.py`):
- Асцендент, MC и дома Плацидуса — из истинного звёздного времени и истинного наклона эклиптики; за полярным кругом — Порфирий;
- истинный лунный узел — по мгновенной (оскулирующей) орбите Луны;
- Лилит — средний апогей Луны по Меусу (гл. 47);
- скорости (ретроградность) — центральной разностью.

Гражданское время рождения читается как UT1: до 1972 года UTC с секундами координации не существовало, а позже UT1 и UTC отличаются меньше чем на секунду.

**Проверка:** на 400 случайных рождениях 1900–2026 годов по всему миру расхождение со Swiss Ephemeris — планеты ≤ 0,001°, Асцендент, MC и дома ≤ 0,001°, узел ≤ 0,02°, Лилит ≤ 0,12°. Эталонные значения Swiss Ephemeris для восьми рождений лежат в `tests/test_astrology.py`.

**Хирон:** в DE421 его нет, а SPK малых тел из JPL Horizons — тип 21, который Skyfield не читает. Поэтому таблица Horizons лежит в репозитории: `apps/astrology/data/chiron.txt.gz` (~330 КБ) — геоцентрическая видимая эклиптическая долгота даты, шаг 1 день, 1900–2053, та же рамка, что у планет. Между днями — линейная интерполяция, ошибка меньше 0,01°. Дата вне таблицы — Хирон просто не попадает в карту.

**Файл эфемерид:** скачивается при первом расчёте в `EPHEMERIS_DIR` (по умолчанию `data/`), в Docker-образ кладётся при сборке.
