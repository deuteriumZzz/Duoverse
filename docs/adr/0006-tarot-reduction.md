# ADR-0006: аркан по дате рождения
**Статус:** принято · 06.11.2026

Аркан = сумма цифр ДДММГГГГ; пока больше 22 — вычитаем 22; 0 → 22 (Шут). Аркан пары = та же редукция суммы двух арканов. Тип связи и оценка пары — правила из `docs/methodology/tarot.md`; таблица 22×22 генерируется из правил командой и может быть вручную донастроена (фикстура), без «магии в коде».
