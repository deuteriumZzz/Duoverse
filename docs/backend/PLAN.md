# Бэкенд: план (Фаза 4 → срезы Фазы 5)

UI и контракт (`apps/compatibility/domain/report.py`) утверждены прототипом. Бэкенд подключается **вертикальными срезами**: каждый срез заменяет часть `FakeReportProvider` настоящим расчётом в `config/container.py`, шаблоны и views не меняются.

## Слои
```
apps/<context>/domain/          чистые функции и dataclass — без Django (тестируются без БД)
apps/<context>/application/     use cases, порты (Protocol)
apps/<context>/infrastructure/  ORM-модели, эфемериды, LLM, кэш
apps/web/                       views, шаблоны (interfaces)
config/container.py             composition root
```

## Что остаётся до запуска (не код)
- **Контент базы знаний:** 78 текстов типов пар, тексты аспектов и арканов пар, вычитка психологических блоков — `manage.py kb_coverage` показывает пробелы.
- **Лицензия Swiss Ephemeris** (ADR-0004) или переход на skyfield.
- **Валидация перевода Mini-IPIP** и своих шкал на выборке; вычитка психологом.
- **Ключ `ANTHROPIC_API_KEY`** в окружении — без него отчёты собираются из блоков.
- Почта (SMTP/ESP) для ссылок переноса, домен, Sentry, бэкапы Postgres.
- Английская локализация, оплата.
