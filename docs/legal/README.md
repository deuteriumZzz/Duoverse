## Что сделать до запуска

### Юридически (решает владелец с юристом)
1. **Выбрать форму:** ИП или ООО. С самозанятостью приём через ЮKassa с чеками по 54-ФЗ не стыкуется — чеки самозанятых идут через «Мой налог»; уточнить у юриста и ЮKassa.
2. **Подать уведомление в Роскомнадзор** об обработке персональных данных (pd.rkn.gov.ru) — до начала обработки.
3. **Локализация данных (ст. 18 ч. 5 152-ФЗ):** база данных с персональными данными граждан РФ должна быть **на серверах в России**. Выбирать хостинг/VPS с размещением в РФ.
4. **Трансграничная передача:** если включать ИИ-сшивку через Claude API (Anthropic, США), нужно отдельное уведомление РКН о трансграничной передаче и согласие пользователя. Проще — не передавать имена (см. «Код» ниже).
5. **Данные партнёра:** пользователь вводит дату рождения другого человека. В согласии и политике это оформлено как гарантия пользователя; юристу проверить достаточность.
6. **Возвраты «Пары+»:** решить, возвращается ли неиспользованная часть периода (оферта, п. 5.6).
7. **Возрастная маркировка 18+** (436-ФЗ): в разборе есть сфера о близости — поставить знак 18+ на сайте.
8. **Лицензия Swiss Ephemeris:** для платного сервиса — коммерческая лицензия Astrodienst или AGPL с открытием кода.
9. **Тексты разбора** проверить астрологу и психологу (особенно сферы «Секс» и «Тени»).
