# Аркан-слой: методика (символический слой)

Код: `apps/tarot/domain/tarot.py` · ADR-0006.

- Аркан партнёра: сумма цифр ДДММГГГГ, пока > 22 — минус 22, 0 → 22 (Шут).
- Аркан пары: та же редукция суммы двух арканов.
- Тип связи:
  | Условие | Тип | Оценка |
  |---|---|---|
  | одинаковые арканы | Зеркальные | 72 |
  | аркан пары объединяющий: Маг, Императрица, Влюблённые, Умеренность, Звезда, Солнце, Мир | Дополняющие | 86 |
  | аркан пары испытывающий: Смерть, Дьявол, Башня, Луна | Напряжённые | 55 |
  | остальные | Нейтральные | 68 |
- Подоценки категорий: страсть выше, если аркан пары — Влюблённые, Дьявол, Солнце или Маг; эмоции — если Жрица, Императрица, Звезда или Луна.
- Тексты арканов и пар — блоки базы знаний `TAROT:arcana:<n>` и `TAROT:pair:<a>+<b>` (срез E0). Никаких предсказаний событий.
