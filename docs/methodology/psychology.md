# Психология: методика (научный слой)

Код: `apps/psychology/domain/` · **все формулировки требуют вычитки психолога до продакшена** (блоки `PSY:*` и привычки этого слоя в базе знаний — в статусе «черновик», в проде показываются только опубликованные).

## Инструменты (шкала 1–5)
- **Big Five:** Mini-IPIP, 20 утверждений (Donnellan et al., 2006; банк IPIP — общественное достояние). Перевод наш, не валидирован — нужна проверка на русскоязычной выборке. Черта = среднее 4 пунктов (обратные пункты зеркалятся) → 0–100.
- **Привязанность:** 8 собственных пунктов по осям тревожности и избегания (конструкт Brennan, Clark & Shaver; опросник ECR-R не воспроизводится). Стиль: обе оси < 3 → надёжный (тревожность ≥ 2,6 → «с тревожными нотками»); тревожность ≥ 3 → тревожный; избегание ≥ 3 → избегающий; обе → тревожно-избегающий.
- **Конфликт:** 10 собственных пунктов — критика, презрение, оборона, уход в себя (по 2) и восстановление (2), по конструктам Дж. Готтмана; опросники Gottman Institute не используются. Уровень: < 2,5 низкий, < 3,5 средний, иначе высокий.
