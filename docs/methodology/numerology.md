# Нумерология: методика (символический слой)

Код: `apps/numerology/domain/numerology.py` · ADR-0005.

## Числа
- **Путь:** сумма цифр ДДММГГГГ → 1–9, мастер-числа 11/22/33 сохраняются. Для сравнения пар мастер-число сворачивается к корню (33→6).
- **Судьба:** сумма букв имени по пифагорейской таблице (кириллица по кругу 1–9: А1 Б2 … И1 Й2 …). Сейчас — по имени из профиля, полное имя уточнит число.
- **Личный год:** день + месяц рождения + текущий год → 1–9.

## Совместимость чисел — явные таблицы
| Пара чисел | Оценка | Формулировка |

Итог слоя = путь × 0,6 + судьба × 0,25 + личные годы × 0,15 (близкие циклы 76, разные 60). Уверенность 95 % с числом судьбы, 80 % без него.

## Матрица судьбы (наша адаптация)
A = день → ≤22, B = месяц → ≤22, C = сумма цифр года → ≤22, D = A+B+C → ≤22, E = A+B+C+D → ≤22.
Точки: Центр личности = E · Отношения = E+C · Предназначение = A+B · Ресурс = C · Зона роста = D. Школы матрицы расходятся; это наш прозрачный вариант.
