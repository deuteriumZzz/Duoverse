# Дизайн-система: «Тёплая лаборатория» + игровые карточки

Направление A из `docs/research/COMPETITOR_ANALYSIS.md` с элементами C (стикер-карточки для шеринга, типов пар и следующих шагов). Токены — `static/src/app.css` → `@theme`.

## Цвет
- Фон — тёплое молоко `#fbf7f2`, поверхности — белые карточки, текст — графит `#1e1a16`.
- **Партнёры:** А — персик `#f2865c`, Б — кобальт `#5470ee`, пара — лимон `#f4c84f`. Мотив бренда — два пятна, перекрывающиеся через `multiply`.
- **Семантика** (всегда цвет + иконка + подпись): синергия — зелёный, нейтрально — тёплый серый, внимание — янтарь, риск — терракота. У каждого тона есть `soft`-фон и `ink`-текст с контрастом AA.
- **Слои:** символический — пунктирная лиловая метка ✦, научный — сплошная шалфейная метка ⚗. Различимы без цвета.

## Типографика
**Manrope** — заголовки (ExtraBold, плотный трекинг) и текст: одна гарнитура, ровный ритм кириллицы. JetBrains Mono — только данные (орбы, проценты, даты). **Playfair Display Italic** — редакционный акцент (`.accent`): ключевое слово в заголовке, слоганы, номера глав. Все с кириллицей.

Главы отчёта отмечаются `.chapter` — курсивный номер + моноширинная подпись (`01 мультивселенная`).

## Знак
Два тонких кольца-орбиты пересекаются; общая линза залита градиентом персик → кобальт; звёздочка — в точке пересечения. Работает в один цвет. Тег `{% mark %}` (`merge=True` — кольца «встречаются», `light=True` — на тёмном).

## Иллюстрации
- **Глифы** (`{% glyph %}`) — собственные дуотон-значки с чернильным контуром для 4 вселенных и 6 категорий; стандартные иконки Lucide остались только для служебных действий.
- **Эмблемы ролей** (`{% role_emblem %}`) — 12 рисунков: искра, костёр, звезда, компас, гора, сад, мост, маяк, ветер, река, гавань, парус.
- **Портрет пары** (`{% pair_poster role_a role_b %}`) — генерируется из двух эмблем в цветах партнёров; фон и композиция зависят от динамики (78 типов пар, 144 портрета с учётом того, кто есть кто). Используется в hero отчёта, мгновенном результате, открытии отчёта, карточке пары, на лендинге (6 примеров) и в скачиваемой карточке 1080×1350.
- Без 3D-наклонов и «голографического» глянца: движение только там, где оно что-то объясняет.

## Форма
Скругления 20–28 px, мягкие тени, `sticker` — карточка с толстой обводкой и «приклеенной» тенью для игровых элементов. Карточки не вкладываются друг в друга.

## Motion
- Появление при скролле (`data-reveal`, ступенчатая задержка `--i`), заполнение шкал и колец, рост радара из центра, счётчики чисел.
- Пружинные кнопки и ховеры (`--ease-spring`), переворот карт арканов, дышащие пятна-партнёры, орбита вселенных.
- Переходы между страницами — View Transitions API.
- **Вау-слой:** слова заголовков поднимаются из маски (`data-split`), маркер-выделение ключевых слов, магнитные кнопки (`data-magnetic`), вспышки частиц на победных моментах (`burst()`), числа-барабаны (`data-roll`), у иконок категорий свой характер (пламя дрожит, сердце бьётся), зерно бумаги, прогресс чтения и сжатие шапки на скролле, морфинг активной вкладки отчёта между страницами.
- **Нижнее меню (мобильное):** активная «пилюля» перетекает между пунктами (View Transitions), иконка пружинит, нажатие сжимает, меню прячется при прокрутке вниз и возвращается вверх.
- **Сцены:** загрузка «сверяем вселенные» после ввода дат (`<template id="tpl-aligning">` + `data-loader` на форме, htmx-задержка свапа и мягкий уход), открытие отчёта (пятна сливаются → балл → тип пары → iris-out), раздача таро из колоды, созвездия синастрии, вытягивание вопроса дня, частицы при генерации, липкая история на лендинге.
- `prefers-reduced-motion: reduce` — всё мгновенно, контент сразу виден.
